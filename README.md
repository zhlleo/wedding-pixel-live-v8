# 婚礼像素默契生存挑战 V8.0 — 30人联机版

## 适合场景
新郎用手机主持，最多30位玩家使用各自手机参加。没有大屏幕也能玩。

## Windows 本地运行
1. 安装 Node.js 20 或更高版本（推荐 LTS）。
2. 解压项目，用 PowerShell 进入解压后的文件夹。
3. 执行 `npm install`（第一次需要网络）。
4. 设置主持密码（至少8位），再启动：

   ```powershell
   $env:ADMIN_PASSWORD="换成你自己的复杂密码"
   npm start
   ```

5. 电脑浏览器访问 `http://localhost:3000/host`，输入密码；玩家端 `http://localhost:3000/`。
6. 如果要用手机测试，手机与电脑连接同一 Wi-Fi，先在 Windows 终端运行 `ipconfig` 找到电脑 IPv4 地址，然后手机打开 `http://电脑IP:3000/`。注意：Windows 防火墙可能需要允许 Node.js 访问专用网络；如果使用 HTTPS 才能正常微信分享，可直接采用下面的云部署。

## Render 云部署（免费方案仅供试用，正式活动请充分测试）
1. 在 GitHub 新建一个**私有仓库**，把本压缩包解压后的全部文件上传到仓库（不要上传 `.env` 或私人密码）。
2. 注册 Render，创建 `New > Web Service`，连接该 GitHub 仓库。
3. Runtime 选 Node，Build Command 为 `npm install`，Start Command 为 `npm start`。
4. 在 Environment 中新增 `ADMIN_PASSWORD`，填至少8位的独立复杂密码。不要把密码写进仓库。
5. 部署完成后访问 Render 提供的 HTTPS 地址：`https://你的服务地址.onrender.com/host`，用手机登录主持人控制台；朋友访问首页链接或扫描主持人页的二维码。
6. 免费实例可能休眠、重启或有资源限制；本版本使用**内存保存房间状态**，服务重启会丢失当前游戏进度，正式聚餐前建议在正式使用的部署配置上测试。

## 游戏规则
- 最多30人，玩家填写姓名、性别，自动获得随机像素人物。
- 新郎在 `/host` 登录，修改题目并点击开始。
- 每道题玩家选择“新郎”或“新娘”，可以在公布前更改。
- 新郎在主持页选择哪一边是正确答案，系统淘汰选错或未答的人。
- 点击“下一题”继续；没有幸存者或最后一题结束时展示结果。
- “全员复活重开”保留玩家身份；“清空全部玩家”需要大家重新入场。
- 刷新页面后通过浏览器 localStorage 恢复玩家身份，前提是服务器没有重启或清空玩家。

## 当前版本限制
- 这是可部署的联机项目源码，尚未在真实30台手机上完成压力测试。
- 当前版本没有微信授权登录、语音、短信通知和数据库持久化。
- 手机端使用像素素材和实时位置插值动画，淘汰时角色滑出场外；没有逐帧物理翻滚特效。
- 目前房间是单一公共房间，不支持多个婚礼同时开局。
- 手机在游戏期间尽量保持网页前台；微信内置浏览器切后台可能暂停动画，回到页面会重新同步状态。
